# 现场连拍帧（2026-10-21）

这两组图是排查「靶纸识别率下降 / 误检率上升」时用 USB 工具直接抓的
K230 原图（640×480），不经过板端 AI，可用于复现评测。

## `scene_20261021/` —— 训练用主场景（60 帧）

- 采集：`cd k230 && python3 -m k230tool grab -n 60 -o /tmp/scene_frames`
- 场景：桌面、靶纸在手机支架上，**靶纸约 33×49 px**，激光光斑压在靶心上；
  画面下方有笔记本电脑（旧的 poseB 模型会把它误检成靶纸）。
- 标注：`tools/label_scene_frames.py --imgsz 416 --conf 0.25`，57/60 帧参与
  中值，逐帧关键点标准差 ≤1.04 px；`check.png` 是 5× 放大核对图。
- 用途：`build_pose_dataset_v3.py --scene-frames tools/scene_20261021`。
  其中前 10 帧进 train，其余按 2:3 分给 val/test。

## `scene_20261021_fresh/` —— 独立测试场景（20 帧）

- 采集时间略晚，云台角度变了，**靶纸约 26×38 px**，激光光斑落在靶纸下方。
- 标注：用旧场景标注的靶纸模板在 `cv2.matchTemplate` 下以 0.75 倍匹配
  （corr 0.79~0.86，20 帧中值），再按框相对位置映射 5 个关键点。
  这是**近似标注**（±2~3 px），只用于评测，不参与训练。
- 用途：检验模型对「没见过的视角 + 更小靶纸」的泛化。

## 注意

- 两组图都没有进 git LFS，单张 40~50 KB，总计约 3.9 MB。
- 场景会变（云台、光照、桌面物品）。换场景后请重新抓帧，用同样的工具
  生成标注，再按 `docs/POSE_V3_TRAINING.md` 的流程补数据。
